# Momo 0.5.0 语音聊天实施与验收

日期：2026-09-08。状态：代码与电脑侧验证完成；未写入开发板，真实模型通话及声学验收尚未完成。

## 本次交付

- S5 只选择聊天，按旋钮开始多轮语音。聊天面板改为非模态区域，其他活动继续使用各自按键和旋钮。再次 S5 不重开会话；常驻打断 / 结束按钮，聊天活动中短按打断或提交，长按结束。确认睡觉结束聊天，单独选 S8 不结束。
- 自有采集、16 kHz 重采样、语音活动检测、识别适配器、流式模型分句、按序播放、上下文及取消控制。播完才计入已听上下文；未播或打断片段不会被当成用户已经听过。纯文字不开麦、不朗读。
- 无键盘优先电脑内置麦克风；键盘连通且支持收音时走键盘音频。旧固件 / UART 桥明确报错并提供用户主动选择的临时电脑收音入口。运行时键盘断开尝试切回电脑；结束和迟到的启动结果不会复活会话。
- 板载麦克风 I2S RX、USB / BLE 音频、独立 ADPCM 帧和采集租约；保留原有按键、音效、电量协议以及共享 GPIO8 电源逻辑。详见 [音频协议](MICROPHONE-PROTOCOL.md)。
- 可配置 HTTPS 识别、Chat Completions 流式对话和可选语音合成服务。默认系统中文声音。密钥只在本次 Momo 服务进程内存中保存，读取配置不会返回密钥；清除配置会取消正在执行的请求。采集音频不落盘，聊天原文不持久保存。
- 桌面音频权限限定为本应用主页面的麦克风请求，拒绝摄像头与其他来源；加入打包后的 macOS 麦克风用途声明，系统睡眠触发会话清理。

## 与原定目标之间的待验收项

1. 尚未使用用户服务配置完成真实识别 → 模型 → 播放的 10 轮对话。设置保存只校验字段格式；需要在应用设置填写密钥后验证模型支持的流式和音频接口。
2. 键盘收音使用手动打断模式，播放时抑制语音提交。尚未实现带播放参考信号的键盘声学回声消除；不能算作外放自然打断达标。电脑麦克风请求浏览器回声消除，仍需 Mac 扬声器外放下验证误触发、500 ms 停播目标与噪声表现。
3. 输出使用 Mac 当前系统设备；电脑输入优先匹配内置设备，未找到时显示实际系统输入标签。没有应用内输出设备选择或独立的录音试播向导；用户可在 macOS 声音设置指定内置扬声器。
4. 固件只完成构建。仍须在单独获准烧录后核验麦克风声道、采样幅度、共享电源稳定、USB / BLE 实际吞吐、掉帧、旋钮和所有按键与音频并行，以及断连 / 重连 / 系统睡眠停麦。
5. VAD 当前是能量检测，初值为起音 100 ms、有效发声 180 ms、静音 800 ms、句长最多 30 s、无发声 60 s 结束。真实近场操作音、持续音乐和环境噪声可能需要调参。模型接口超时 30 s；实际首次回应延迟尚未测量。
6. 声音由系统或用户配置的 TTS 提供；系统可用中文音色、首次加载、音量调节及外放体验尚未实听。应用未签名 / 公证。

以上待验收项保留为产品目标，不能以测试替身或编译成功代替真实语音验收。
