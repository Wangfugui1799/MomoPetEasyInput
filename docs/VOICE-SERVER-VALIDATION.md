源码导入时，16 个上游文件仅规范了行尾空白／换行；来源清单同时保留原始 Git blob 标识及规范化文件列表。Momo 适配入口和配置是独立文件。

## 可重复的电脑检查

在项目根目录完成安装后运行：

```sh
npm test
npm run test:voice-server
npm run voice:check
```

`voice:check` 需要已填写 `.env`，但不会验证远端密钥。完整服务验证应按 [使用教程](VOICE-SETUP.md) 启动服务，确认健康检查后说话，观察转写、回答和声音。
