# 操作音效 0.2.0 开发与验证记录

日期：2026-09-06。以下保留开发阶段的电脑测试记录。后续已完成应用烧录、正常启动、真实设备音效状态读取及新版桌面连接，详见 [最新烧录记录](FLASH-STATUS.md)。用户随后反馈“不错”，初步认可使用效果；以下未验证项为开发阶段记录，后续分项实板结论以烧录记录为准。

## 实现

- 八键在有效按下时发按键音，旋钮每个逻辑步进发旋转音，旋钮按下发确认音；声音不等待电脑，释放和长按判定不重复发声。
- 独立音频任务输出 16 kHz / 16 bit / 双声道 PCM，三类 20 毫秒短音带平滑包络。25 毫秒声音合并窗口、单项待播邮箱与过期丢弃避免持续补响。输入扫描不调用阻塞音频写入。
- 默认开启、音量 30%；设备 NVS 保存开关和音量，非法配置或存储初始化失败时静音，不擦除 NVS。
- 设置界面增加开关、音量、试听和重新读取。兼容旧固件；未连接或旧固件不允许操作音效设置。保存成功由对应设备回执确认，超时、写入失败或断连不显示成功。
- USB / UART 独立解析配置命令，并向请求来源回复；保留原有按键事件、旋钮短按/长按语义与输入丢包计数。
- 更新 Mac 应用及固件版本至 0.2.0，协议主版本保持 `momo-easyinput/1`，通过 `sound:true` 声明能力。

## 实板验证边界

1. 尚未验证真实扬声器出声、舒适音量、底噪或爆音。音频驱动初始化和播放故障尚未在实板注入；电脑测试中的音频失败回执使用替身状态。
2. GPIO8 安全初始化后上电，等待 50 毫秒是本项目待资格确认值，不是板级测得的最小稳定时间。烧录前需核对供电稳定条件；当前没有示波器、电源波形或批次测量证据。
3. GPIO8 保持开启，静音不关共享电源；尚未实现麦克风和 LED 业务，不能声称共存测试已通过。待实板核对静态电流、发声时电源表现和其他外设状态。
4. 消抖保留 20 毫秒。修正了原需求将先后阶段取最大值的错误预算：普通操作目标是识别后 20 毫秒内开始出声，物理按下至声音约 40 毫秒目标，需同步物理输入与声波测量。快速连续输入按 25 毫秒合并窗口处理。
5. NVS 断电持久化使用 ESP-IDF 接口，电脑已测配置格式与失败回执，实板断电恢复和写入失败后的实际存储状态尚未验证。
6. 实板还需验收逐键、旋钮每格步数和方向、快速连续操作、独立供电、10 分钟混合操作。声音计数与主机输入队列丢包应分别记录。
