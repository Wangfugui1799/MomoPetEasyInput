# Momo 0.4.0 电量显示

新增连接状态旁的键盘电量百分比。GPIO5 使能电池分压，等待10ms后通过 GPIO4 / ADC1_CH3 读取16次校准电压，恢复约2倍分压后按满电4200mV比例换算百分比，最高100%。采样结束关闭 GPIO5。没有专用电量计，当前数值来自电压换算，尚未做实板校准。

每10秒采样并通过 USB JSON battery 事件和 BLE 类型5发送百分比。未知读数用 USB -1 / BLE 255；前端显示“电量未知”，25秒没有更新显示“电量待更新”，断开隐藏。蓝牙协议版本仍为1，旧App忽略未知类型。

电脑验证：Node 19/19，浏览器8/8（含模拟85%电量和断开隐藏）。ESP-IDF 5.5.5 构建输出在 firmware/build-ble，Mac应用在 dist/Momo-darwin-arm64/Momo.app。

本版尚未烧录。需要核对实板电压、实际电量显示以及采样稳定时间。

## 实板更新

用户确认后，MAC 尾号 D6:80 的 ESP32-S3 已写入0.4.0，启动程序、分区表和应用三段哈希校验通过，未整片擦除。自动恢复后收到0.4.0握手，POST_FLASH_READY=yes。随后只读采集收到真实 battery 事件，percent=96。App显示仍需重启新版并重新连接后确认；当前读数为电压换算值。
