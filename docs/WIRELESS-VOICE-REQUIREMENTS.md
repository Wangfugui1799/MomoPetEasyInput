# EasyInput 无线语音 V0.6.0

日期：2026-09-11。实现目标：BLE 配网与控制、Wi-Fi 音频、Mac 播放回复。

## 用户流程

1. 首次将 0.6.0 开发板通过原生 USB 连接 Momo，在设置中绑定这台 Mac。绑定密钥由 Mac 随机生成，经 USB 传入板端；不要求用户手工复制密钥。
2. 选择 Mac 的局域网地址，开启无线接收；通过 Momo 蓝牙连接，在设置中填写 2.4 GHz Wi-Fi 名称与密码并配网。Mac 可以有线或无线接入同一个可互通局域网。
3. 设置默认输入为“EasyInput · 板载麦克风（Wi-Fi）”。桌面 0.6.3 按用户新要求：S5 按一下开始录音、再按发送，回复后待命；聊天活动中旋钮短按只显示对话框。聊天框麦克风按钮仍保留旧连续模式，具体操作见 [S5 按键留言](S5-VOICE-MESSAGE.md)。
4. 配网和绑定保留，重启后可开启无线接收重连。日常不需要 USB。地址变化时通过 BLE 更新配网；没有自动搜索整个局域网。

## 数据路径

板端 I2S → 有界音频队列 → 经认证的 TLS → Electron 主进程 → 窄接口 IPC → 现有 KeyboardMicrophone / Silero VAD → 本机语音后端 → Mac 扬声器。

沿用 16 kHz / PCM16 / mono 和 128 样本帧，在 TLS 中复用已有 JSON Lines 音频格式，降低 USB 与无线分支的协议差异。原始 PCM 为 32,000 字节/秒，封装后带宽需实测。使用 TLS 1.2 ECDHE-PSK-CHACHA20-POLY1305，兼容 Electron 40 的 BoringSSL 与 ESP-IDF 5.5.5 的 Mbed TLS。配网另用派生密钥 AES-256-GCM，设备随机挑战仅用一次，拒绝重放、乱序分包及认证失败。

## 交互和范围

- USB 与 Wi-Fi 音频为互斥收音来源，不能互相续租或停止。BLE 仍传按键、旋钮、电量。
- 默认不收音；用户开启后续租，思考与播放期间停止；关闭麦克风、应用退出、断线、音频丢帧、积压或租约过期时停止并提示。重连不自行恢复录音，也不切换到电脑麦克风。
- USB 麦克风、文字聊天和其他活动继续可用。回复保持从 Mac 播放。
- 接收端只监听用户选择的本地 IPv4 地址和固定端口 4786，首次默认关闭，单板单会话；不开放原语音后端的 loopback 监听。2026-09-11 按用户自动连接需求，桌面 0.6.2 保存开启状态和地址，重启自动恢复；手动关闭会取消恢复，异常或地址变化不回退到其他网卡。自动联网/接收不自动录音。
- 配网只支持 WPA2/WPA3 Personal 的普通 2.4 GHz 网络；企业 Wi-Fi、认证网页、跨网段发现和公网服务不在本版范围。
- Mac 通过系统安全存储加密保存绑定信息；Wi-Fi 密码只在配网期间出现在内存中，板端保存在本地 NVS。板端不启用 Flash 加密，物理读出防护不属于本版承诺。
- 绑定其他 Mac / 重新绑定需再次连接 USB。首次 USB 绑定是这块无显示屏设备的信任建立步骤。

## 硬件与验收

沿用 EasyInput V2.0 / AI Keyboard V2.1：麦克风 GPIO9/10/11、I2S1，扬声器 I2S0；GPIO8 共享电源、GPIO12、BOOT 流程保持原合同。

先完成电脑逻辑、加密认证/重放、真实 TLS 软件往返、固件宿主、UI 回归和 ESP-IDF 构建。实板验收另行进行：配网、断电重连、拔 USB 连续真人三轮、同时按键/旋钮、Wi-Fi/BLE 共存、延迟、回声、停止与断线。构建和模拟音频不代表实板语音通过。
