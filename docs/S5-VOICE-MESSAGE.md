# S5 按键留言（桌面 0.6.3）

日期：2026-09-12。按本轮用户要求替换原「S5 只选聊天、旋钮确认开始」操作；不修改固件和引脚。

## 操作与范围

1. Momo 和语音后端保持运行，设置里选好 USB、Wi-Fi 或电脑麦克风。无线使用须先连好音频链路；S5/旋钮控制还需要应用内 BLE 或 USB 控制连接。
2. 按一次 S5，选择聊天并开始准备收音；看到「正在录音 · 说完再按 S5 发送」后说话。不弹出对话框，停顿或多句话都不会提前发送。
3. 再按一次 S5，停止收音，等停止确认后将这一整段留言发送给语音后端，识别并由 Mac 播放回复。发送/回复期间重复按 S5 只提示稍等，不会重复提交或重新录音。
4. 回复结束保持同一聊天会话，但麦克风暂停。再次按 S5 才录下一条留言，不会自动监听第三轮。
5. 聊天活动中短按旋钮只显示聊天对话框，不开始、不发送录音。其他活动的旋钮仍执行各自的原功能。聊天框打开时，实体 S5 仍能控制录音/发送；关闭窗口不停止进行中的留言或播放。
6. 点「关闭麦克风」可结束会话、丢弃尚未发送的录音。切换音源、退出应用或录音时断线也停止，不自动回退音源。

屏幕 S5 和非输入框/弹窗内的数字键 5 使用相同按键留言逻辑；数字键不能抢占聊天输入框中的数字输入。新增「打开聊天对话框」按钮用于无需录音的文字聊天。聊天框的麦克风按钮仍保留旧的停顿自动发送/连续聊天模式；使用它期间需先关闭，再用 S5 切换到按键留言，避免中途改变发送规则。

## 边界

- 每段最多 60 秒，达到上限停止并丢弃，不自动代发。少于 0.4 秒不提交，提示重新录音。
- 板载麦克风直接缓存 16 kHz PCM，不再用 VAD 切句；电脑麦克风复用已有采集和重采样，每帧进入有界缓存，忽略 VAD 自动结束事件。缓存只在内存，不生成本地录音文件。
- 等待后端初始化期间不接受第二次发送；以「正在录音」提示作为开始说话的时机。
- 本版不声称修复现有 Wi-Fi/TLS 断线根因。用户报告的问题是两轮后、第三轮开口前断开；改为手动录下一条能改变收音时机，但不能代替断线原因诊断。
- 使用现有 0.6.0 固件，无需重新烧录；保留桌面 0.6.1 连续模式修复、0.6.2 无线接收记忆。

## 验收要求

- USB 与 Wi-Fi 分别完成三组 S5「录音→发送→回复→待命」，每组只有一次提交、一次录音启停，没有回复后自动重开。
- 录音时停顿超过一秒仍不提交；弹窗打开时实体 S5 可以发送；旋钮只控制聊天框；喂食、训练等活动的旋钮功能保留。
- 覆盖快速重复按键、过短/取消、断线、切换输入、不回退、电脑麦克风多段语音及静音的完整缓存。
- 自动化的硬件、语音后端和电脑采集桩不能代替实板真人三条留言。新包为 `dist/s5-message/Momo-darwin-arm64/Momo.app`；退出旧 Momo 后启动，不需要重新配网。
