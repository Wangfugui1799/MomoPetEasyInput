# 键盘按键与旋钮本机声音反馈需求文档

版本：V0.1 草案

日期：2026-09-06

适用产品：EasyInput 当前八键、可按压旋钮硬件

## 1. 目标

用户按下键盘按键、转动旋钮或按压旋钮时，键盘自身立即发出轻短的提示音，让用户通过声音感知操作已被设备识别。

声音由键盘内置扬声器播放，正常供电时不依赖电脑扬声器、桌面应用或网络。声音表示输入被识别，不表示电脑端对应动作已经执行成功。

## 2. 范围与默认方案

本期覆盖 S1～S8 八个按键、旋钮双向旋转和旋钮按压。保留现有按键与旋钮功能，在原有输入行为上增加声音反馈。

以下默认值为本需求提出的产品方案，尚未进行实板试听或性能验证。

| 项目 | V0.1 默认方案 |
| --- | --- |
| 总开关 | 首次使用默认开启，可关闭 |
| 音量 | 默认 30%，可调 0～100%；百分比表示软件音量档位，不代表声压 |
| 按键音 | 八个按键使用同一种轻短“嗒”声 |
| 旋转音 | 顺、逆时针使用同一种更轻的“滴答”声 |
| 旋钮按压音 | 使用与普通按键可区分的短确认音 |
| 设置保存 | 开关和音量保存在设备，断电重启后恢复 |
| 设置入口 | 在现有配置界面增加“操作音效”开关、音量滑块和试听按钮 |

本期不增加语音播报、自定义音频上传、逐键配音、音效主题商城或开关机音效。

## 3. 输入与声音规则

| 用户操作 | 声音行为 |
| --- | --- |
| S1～S8 任一按键有效按下 | 每次按下播放一次按键音 |
| 松开按键 | 不发声 |
| 按住按键或触发长按 | 按下时响一次，持续按住和长按判定不追加声音 |
| 双击按键 | 两次有效按下各响一次，不额外追加双击音 |
| 旋钮顺时针或逆时针转动 | 每个有效旋转步进触发一次旋转音 |
| 旋钮按压 | 每次有效按下播放一次确认音；松开不发声 |
| 按住旋钮并旋转 | 按压和旋转分别按各自规则处理，原有组合操作保持不变 |
| 输入接点抖动、无效相位变化 | 不发声 |
| 电脑端模拟输入或配置同步 | 不自动播放物理操作音；点击试听除外 |

旋转步进使用消抖和方向解码后的逻辑事件；不得把 A/B 相每次电平变化分别当成一次用户操作。实际一格对应多少相位变化，需在目标固件和实板上核对。

## 4. 连续操作与声音冲突

- 普通操作下，一个有效输入对应一次短音；各类音效建议长度为 15～40 毫秒，最终以试听为准。
- 快速旋转时允许合并密集声音：相邻声音起点至少间隔 25 毫秒，窗口内优先保留最新旋转反馈。合并仅影响声音，不丢弃输入动作。
- 同时按下多个按键时，各按键动作全部保留；同一 25 毫秒窗口内的按键音可合并为一次。
- 音效不建立持续增长的播放队列。停止操作后，100 毫秒内结束剩余操作音，避免出现滞后补响。
- 按键或旋钮按压与旋转音冲突时，优先播放按压反馈。音效切换需使用短淡入淡出，避免爆音。
- 若设备已有其他音频播放，本期其他音频优先，冲突期间可省略操作音，且不在播放结束后补响。

## 5. 设置交互

用户在“操作音效”区域直接开启或关闭声音，并调整音量。调整后的设置发送到设备并保存；界面只有收到设备确认后才显示保存成功，断连或失败时明确提示未保存。

关闭总开关或音量为 0 时，所有操作音和试听均静音。重新开启时恢复上次音量。试听由键盘播放一次按键音，不触发真实按键动作；设备未连接时显示不可试听。

保存应在一次拖动结束或短暂稳定后进行，避免拖动音量滑块时频繁写入存储。新配置缺失时使用默认值；配置损坏时回退为静音，并允许用户重新设置。

## 6. 性能与可靠性要求

- 操作音必须在设备本地触发，不等待电脑响应。
- 延迟目标：常规非合并操作从有效输入识别到声音开始不超过 20 毫秒；现有按键消抖为 20 毫秒，因此从物理按下开始的目标预算为约 40 毫秒，另计采样误差。两段时间先后发生，必须相加。快速操作按第 4 节的 25 毫秒合并窗口处理。验收采用同一时基测量物理操作与声波起点。
- 声音播放不得阻塞输入扫描、旋转解码或现有通信；高频操作时优先保证按键和旋钮功能。
- 音频初始化或播放失败时，输入功能继续工作，不反复重启；诊断中保留可定位的错误信息。
- 无操作时保持安静，不应出现持续底噪、重复鸣叫或上电爆音。
- 如已有睡眠功能，进入睡眠前结束音效；唤醒后仅对可确认的有效输入发声，不凭聚合唤醒信号补造按键音。唤醒首音延迟单独测量并记录。

## 7. 硬件约束与待验证项

当前硬件资料对应 EasyInput V2.0，PCB 丝印 AI Keyboard V2.1；两者在本需求中指同一硬件基线。

- 板载扬声器通过 MAX98357A 路径连接；BCLK / WS / DOUT 分别为 GPIO14 / GPIO13 / GPIO15。
- GPIO8 是 LED、麦克风、扬声器的共享高有效电源。声音开关应控制播放，不能通过单独切断 GPIO8 实现静音并影响其他外设。
- 共享电源上电前需设置安全引脚状态，稳定后才能使用音频；关断前需协调所有共享消费者停止活动。稳定等待条件应由器件资料或实测确认。
- 采样率、声道、缓冲和音频资源格式属于实现阶段选择，不作为已验证的硬件默认值。
- 需确认实板扬声器装配和出声链路、音量上限、底噪、峰值电流，以及与灯光和已有麦克风功能同时使用时的表现。

资料依据：`easyinput-board-cy/references/pinout.md` 与 `easyinput-board-cy/references/power-and-peripherals.md`。这些是硬件资料确认，不代表当前固件已支持声音或实板已经验收。

## 8. 验收标准

| 场景 | 通过条件 |
| --- | --- |
| 八键逐个测试 | 每键重复按下 20 次，慢速操作下一次一响，松开不响，无重复触发 |
| 长按与双击 | 长按仅首次按下发声；双击两次发声，无额外提示音 |
| 旋钮双向慢转 | 每方向各 20 个有效步进，每步一响，无静止误响 |
| 旋钮按压及组合操作 | 按压发确认音；按住旋转时原功能和声音规则一致 |
| 多键与快速旋转 | 输入功能完整，声音按合并规则执行，停止后 100 毫秒内安静 |
| 声源与独立性 | 关闭电脑声音并退出桌面应用后，键盘正常供电时仍可发声 |
| 开关、音量与保存 | 关闭或音量 0 时静音；设置成功后断电重启保持一致 |
| 延迟 | 使用物理输入与声波起点的同步测量验证目标，不能用日志时间代替实际出声 |
| 音频异常 | 模拟初始化或播放失败，按键、旋转和通信继续工作 |
| 外设共存 | 播放、静音和调音量不导致 LED 异常；已有麦克风功能不受影响 |
| 持续使用 | 连续混合操作 10 分钟，无卡死、异常重启或持续补响 |

验证分两阶段：先在电脑上验证触发、去抖、合并、设置持久化和异常逻辑；再在获得实板写入授权后验证出声、延迟、音质和外设共存。电脑测试或构建通过不能替代实板声音验收。

## 9. 评审重点

建议优先评审默认开启、30% 初始音量和三类轻短音效是否符合日常使用偏好。音色样本及舒适音量范围在后续试听阶段确定。

需求状态：V0.1 已进入开发。实现与验证记录见 [INPUT-SOUND-VALIDATION.md](INPUT-SOUND-VALIDATION.md)，实板结果单独记录。
