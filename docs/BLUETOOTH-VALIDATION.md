# Momo 0.3.0 蓝牙控制验证

日期：2026-09-07。此记录区分电脑模拟、构建与真实硬件。

## 实现

- ESP32-S3 NimBLE 自定义 GATT 服务，广播名 `Momo EasyInput`，开机广播，断开后恢复广播，最多一个 BLE 连接。
- 服务 UUID `4d4d0000-0000-0000-0000-000000000001`；只读/通知特征 `4d4d0000-0000-0000-0000-000000000002`。
- 每个通知固定 3 字节，适用于默认 ATT MTU：版本 `1`、类型、值。类型 0=心跳（值0）、1=按键（1–8）、2=旋转（有符号±1）、3=短按（0）、4=长按（0）。连接后读取特征确认版本，心跳每2秒，失联超过6秒断开。
- USB JSON 协议仍兼容。蓝牙只接收控制事件；键盘音效继续本机播放，设置通过 USB。
- Mac 应用使用 Web Bluetooth，由用户选择设备；包含 macOS 蓝牙权限用途说明。取消选择和断开清理不保留事件监听。
- 这不是标准 HID 键盘；在 Momo 内连接，不依赖系统蓝牙键盘配对列表。当前没有绑定或身份认证，只允许一个近距离 BLE 客户端连接。

- 浏览器测试 8/8：包含模拟 BLE 喂食、旋钮、确认、USB 音效设置提示、断开；原有串口回归通过。
- 固件宿主输入与音效逻辑测试通过。
- ESP-IDF 5.5.5 / ESP32-S3 独立构建通过；输出在 `firmware/build-ble/`，使用该目录内的 SDKCONFIG。没有覆盖原有构建配置。
- UI 截图已检查，顶部可见“蓝牙连接”。

## 2026-09-07 实板烧录更新

用户明确确认烧录后，原生 USB `/dev/cu.usbmodem1101` 识别为 ESP32-S3，MAC 尾号 D6:80。Momo 0.3.0 三段写入成功：0x0 启动程序 20816 字节、0x8000 分区表 3072 字节、0x10000 应用 498944 字节，每段哈希校验通过。未整片擦除，未写入 NVS 分区。恢复正常启动前再次核对 MAC 一致。

本轮为手动 BOOT 进入下载模式。当前等待用户用电源开关关机再开机；应用启动、BLE 广播及真实按键仍待验证。新版应用已打包，原有正在运行的 Momo 需要重启才能加载蓝牙入口。
